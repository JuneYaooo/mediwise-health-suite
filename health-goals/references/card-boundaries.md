# 目标证据卡边界

目标证据卡是对“用户已设目标 + 已记录行动 + 出现新的行为含义”的静态纪念物，不是诊断报告、建议书、普通健康数据摘要或进度页截图。

## 发卡门槛

每张卡必须同时满足：

1. 有明确、可复核的落库证据。
2. 相比进度页增加了新的行为含义，例如节奏、恢复、连续稳定或完整结束。
3. 能解释“为什么获得”。
4. 能给出不超出用户原目标的下一步。

普通打卡、普通单周完成和任意百分比换皮均不满足门槛。没有足够证据时返回轻反馈，不生成卡。

默认可展示：目标标题、阶段类型、触发当时的打卡次数、星期分布、间隔天数、周期或整体进度、非精确的“阶段证据”日期标签。默认不展示：成员姓名、精确日期、原始健康读数、疾病、药物、检验、绝对体重或设备来源详情。

只有用户明确要求时，才展示姓名或精确日期。即使用户授权，也不要把与阶段无关的医疗数据塞进卡片。

文案规则：

- 标题要陈述具体含义，例如“找到了第一套可重复的节奏”，不要写“这一阶段完整落地”之类空泛口号。
- 写“已记录”“连续完成”“重新接上”，不写“战胜懒惰”“不能停”“必须坚持”。
- 中断不等于失败；不补写空白，不暗示未记录日一定没有行动。
- 只把已落库证据称为完成，不根据趋势预测未来达成。
- 下一步只能延续原目标、继续记录或由用户决定是否开启新目标；不能自动加量。
- 不用体型、年龄、疾病风险或目标完成度决定审美风格。

卡片从里程碑冻结快照生成。后续打卡不得改变旧卡上的打卡数、行动分布或阶段进度。

偏好文件只保存成员 ID 摘要、语气、信息密度、喜欢/拒绝/近期样式和生成次数，不保存目标值、打卡值或健康读数。卡片与偏好均位于本地数据目录。目标和卡片删除沿用系统软删除语义。
