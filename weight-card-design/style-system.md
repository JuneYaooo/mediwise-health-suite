# MediWise 体重译报叙事系统

## 一句话原则

24 套模板不是 24 张换色皮肤，而是 **24 种视觉轮廓 × 24 个内容角色 × 6 类主导信号**。健康分析决定“能说什么”，可用数据、用户偏好与使用场景决定“怎么说”，小概率探索负责偶尔带来惊喜。

## 体重管理分析，不是只分析体重

```text
同日体重中位数 + Theil–Sen 稳健趋势
              │
              ├── 有记录日饮食摄入与营养
              ├── 已记录运动日、时长与运动消耗
              └── 有记录日睡眠时长
                         ↓
              数据资格与覆盖检查
                         ↓
              同期综合分析段（不推断因果）
```

- 未记录的饮食日、运动日或睡眠日不按 0 处理。
- 摄入平均值必须写成“有记录日平均”。
- `calories_burned` 只称“已记录运动消耗”，不是全天总能量消耗。
- 不用摄入减运动消耗计算热量缺口，也不输出理论体重变化。
- 只说“这些变化发生在同一阶段”，不说某项变化导致体重上升或下降。
- 饮食和睡眠至少 3 个记录日、运动至少 2 个记录日才概括；前后半段各自达不到门槛时不做阶段比较。

每张卡都包含一段综合分析，但会按物件语法转译为气象简报、船长日志、编辑导语、馆藏说明、场记、唱片内页或档案结论，而不是统一放进同一种分析框。

## 阶段肖像与自媒体分享结构

卡片先用确定性规则总结“这个用户最近处在什么记录状态”，再进入模板叙事。阶段肖像不是随机鸡汤，也不是健康评分：

- 最新秤面与长期趋势相反：`今天抢镜，长线没改剧本`；
- 四域数据齐全、至少两条生活记录线在后半段发生可比较变化：`后半场换挡`；
- 四域数据齐全但分段变化不明显：`节奏守恒局`；
- 四域已经接上、分段比较仍不足：`四线同框，剧情待续`；
- 某一生活方式域覆盖明显更高：`聚光灯落在摄入 / 运动 / 睡眠`；
- 只有两条生活记录线达到分析门槛：`两条生活线已经接上`；
- 只有一条生活记录线达到门槛：`摄入 / 运动 / 睡眠先开口`；
- 生活方式数据不足：`线索还在加载`。

分享卡采用自媒体的静态首帧逻辑，但不使用标题党：

```text
结果先行的阶段肖像
→ 一句好奇缺口或反常识解释
→ 2～3 条真实数字证明
→ 完整综合分析与因果边界
→ “保存这张，下一段回来和自己对照”
```

分析结果同时生成 `social_packaging`：`cover_hook`、`cover_subhook`、`proof_points`、`save_prompt`、默认脱敏 `share_caption`、钩子机制和 `clickbait: false`。自媒体包装只能放大已确认的个人事实，不能放大风险、制造羞耻或许诺结果。

## 内容差异契约

同一份分析结果在 24 套模板中保持事实一致，但不应复制同一篇文案。每套模板必须有唯一的 `content-role`、唯一的 `layout-mode` 和固定主导信号，并主动选择“先说什么、用什么物件说”。

| 母风格 | A 版的内容任务 | B 版的内容任务 | 主要证据 |
|---|---|---|---|
| 身体气象 | 此刻的单日天气 | 整段观测是否连续 | 单日变化、长期方向 / 覆盖率、空白、复测 |
| 航行记录 | 短期浪高与长期航向是否冲突 | 一本可核对的阶段日志 | 单日变化、稳健趋势 / 跨度、页数、净变化 |
| 地形探索 | 阶段振幅生成的等高线 | 起点到终点的穿越路线 | 极差、典型起伏 / 净变化、最大单步变化 |
| 编辑出版 | 证据最多支持的结论 | 只放大一个值得带走的事实 | 趋势、样本、可信度 / 今日数字、是否改写长期 |
| 时间收藏 | 封存阶段快照 | 给下一次回看的信 | 记录日、净变化、编号 / 今日、跨度、当前证据 |
| 胶片日记 | 最近六格的连续变化 | 九个真实切片的联系印样 | 最大格间起伏、净变化 / 测量次数、同日复测 |
| 节律日历 | 个人记录节拍 | 覆盖率生成的观测相位 | 记录日、空白、复测 / 覆盖率、最长空白 |
| 里程旅程 | 从此刻出发的观察车票 | 只奖励观察行为的阶段印章 | 跨度、站点、净变化 / 记录人格、证据等级 |
| 唱片音乐 | A/B 两面收录两个时间尺度 | 只发行一个本周观察 | 今日、长期、覆盖 / 单一状态与底注 |
| 身体来信 | 用第一人称转述事实 | 把不确定性写成完整序章 | 必要的今日与长期事实 / 已有记录与还缺的证据 |
| 个性标签 | 一眼记住的观察者人格 | 私人观察档案 | 记录跨度与习惯 / 密度、复测、可信度 |
| 生成艺术 | 记录点生成的星图 | 覆盖与振幅生成的指纹 | 点数、振幅、编号 / 覆盖、振幅、编号 |

实现层必须持续满足：

- 24 个 `content-role` 唯一；
- 24 个 `layout-mode` 唯一，缩略图轮廓可辨；
- 体重、摄入、运动、睡眠、记录行为和综合分析都有对应主导模板；
- 不强制所有模板使用统一 Hero 和三宫格指标；
- 每张必须出现专业分析段，但标签、位置、宽度、排版角色不能全部相同；
- 风格只能取舍、重排和转述已确认事实，不能改写分析结论。

主导信号分配：

| 主导信号 | 模板 |
|---|---|
| 体重 | 身体天气预报、身体航向、身体等高线、本周身体头条 |
| 摄入 | 身体数据刊物、时间胶囊、本月九宫格、数据指纹 |
| 运动 | 航海日志、山谷与高地、健康车票、身体唱片 |
| 睡眠 | 一周气象档案、写给未来的身体、月相日历、身体给你的信 |
| 记录行为 | 身体胶片、身体节律、身体护照、记录者人格卡 |
| 综合分析 | 本周身体单曲、今天先不下结论、身体观察档案、身体星图 |

## 趣味逻辑

选择器先从记录中识别“故事时刻”，再调整模板权重：

| 故事时刻 | 触发条件 | 更容易出现的表达 | 安全边界 |
|---|---|---|---|
| 故事刚刚开始 | 少于 4 个记录日 | 今天先不下结论、健康车票、身体来信 | 不伪造趋势 |
| 今天出现剧情反转 | 单日方向和长期方向相反 | 身体头条、本周单曲、天气、航向 | 不把上升/下降写成成功失败 |
| 信号正在变清楚 | ≥7 个记录日且覆盖率 ≥70% | 节律日历、身体护照、观察档案 | 奖励记录，不奖励体重结果 |
| 一格双重曝光 | 同日存在多次测量 | 身体胶片、数据指纹 | 先取中位数，不挑最好看的数字 |
| 一段安静水流 | 趋势可陈述且处于稳定区间 | 等高线、身体来信、月相 | 稳定不等于医学健康 |
| 长线视野已解锁 | 跨度 ≥28 天且 ≥10 个记录日 | 山谷、星图、指纹、时间胶囊 | 不预测未来结果 |
| 记录重新接上了 | 两个记录日间隔 ≥5 天 | 身体来信、时间胶囊、车票 | 不用断签惩罚或内疚文案 |

## 记录者人格

人格只描述记录行为：

- 刚刚启程的人：记录仍在序章。
- 稳稳记录者：正在积累个人记录。
- 节律收藏家：覆盖较连续。
- 细节观察者：存在多个同日记录。
- 长线观察者：观察跨度较长。

禁止从 BMI、绝对体重、趋势方向、性别、年龄、疾病、用药或目标完成度生成审美与人格。

## 非均匀概率

基础权重有意不相等；选择器再按以下顺序处理：

```text
数据资格过滤
→ 场景权重
→ 语气/密度偏好
→ 当前可用的摄入/运动/睡眠信号
→ 明确喜欢或拒绝
→ 最近历史防重复
→ 故事时刻加权
→ 8%～18% 探索混合
→ 归一化并选择
```

主要系数：

- 当前场景匹配：`×1.50`，不匹配：`×0.32`。
- 用户喜欢：`×1.80`。
- 用户要求少出现：`×0.03`。
- 上一张刚使用：`×0.30`。
- 最近三张出现至少两次：再 `×0.15`。
- 上一张属于同一母风格：兄弟模板 `×0.68`。
- 探索率：`8% + surprise_level × 10%`。
- 用户固定模板：资格满足时概率为 `1`；资格不满足时明确报错，不偷偷换模板。

探索不是完全随机。它倾向最近没出现过的母风格，也会适度提高稀有模板的机会；明确拒绝过的模板即使在探索池也继续受到强惩罚。

## 可复现视觉签名

选择器会为每次结果返回：

- `edition`：脱敏版本编号；
- `palette_variant`：同一母风格内的配色变体；
- `composition_variant`：构图变体；
- `texture_seed`：生成星图、指纹、地形或唱片纹路的稳定种子；
- `reproducible: true`：相同 seed 得到相同选择与视觉签名。

这使模板不只是在 24 张固定背景中抽一张：同一模板也能根据用户数据生成稳定而不同的个人作品。

## 生成接口

完整生成使用 Node action `generate-weight-story-card`：

```json
{
  "action": "generate-weight-story-card",
  "member_id": "<member-id>",
  "params": {
    "days": 14,
    "scene": "share",
    "tone": "playful",
    "style": "auto",
    "format": "both",
    "show_exact_weight": false,
    "show_member_name": false,
    "show_exact_date": false
  }
}
```

它会按顺序完成：稳健体重分析、摄入/运动/睡眠同期分析、各域覆盖检查、偏好读取、风格选择、1080×1440 HTML/PNG 渲染和最近风格历史写入。传入具体 `style` 可以固定模板；数据不满足体重趋势门槛时明确报错，生活方式域不足时诚实留白，不补造数据。`save_history: false` 可以生成但不写入最近历史。

## 选择预览接口

Node action：`select-weight-card-style`。主要输入：

```json
{
  "action": "select-weight-card-style",
  "member_id": "<member-id>",
  "params": {
    "days": 14,
    "scene": "share",
    "tone": "playful",
    "density": "concise",
    "preferred_styles": ["weather-now"],
    "disliked_styles": ["editorial-cover"],
    "recent_styles": ["direction-course"],
    "surprise_level": 0.6,
    "seed": "optional-reproducible-seed"
  }
}
```

输出包含 `selected_style`、完整 `probabilities`、`eligibility`、`reasons`、`exploration`、`story_moments`、`observer_persona`、`visual_signature` 与选择边界说明。

## 兼容入口

- `weight-truth`：保留原结构化分析结果。
- `generate-weight-card`：保留原「体重真相卡」经典航向版、参数和输出结构。
- `generate-weight-story-card`：新的「体重译报」完整个性化生成链路。

新功能没有替换旧动作，也没有改变旧分析阈值或健康数据库 Schema。

## 本地风格记忆

`weight-card-preferences` 读取偏好，`update-weight-card-preferences` 更新偏好。可以保存：

- 喜欢、拒绝或恢复中性的模板；
- 固定模板；
- 温柔、冷静、有趣、编辑感或大胆等语气；
- 简洁或详细的信息密度；
- 惊喜程度；
- 最近 6 次实际生成的风格与累计生成次数。

偏好文件位于 `MEDIWISE_DATA_DIR/weight-card-preferences.json`，目录权限尝试设为 `0700`、文件为 `0600`。成员 ID 先经过 SHA-256 摘要；文件不保存体重、BMI、趋势、疾病、用药或卡片正文。只有真正生成卡片后才应通过 `generated_style` 写入历史，单纯预览推荐不会消耗一次历史。
